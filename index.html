如何确认是否使用了 v2rayN

本页面只能确认“出口 IP 变了”。它不能单独证明流量使用的是 V2Ray、Xray、Clash 还是其他代理内核。

  1. 在 v2rayN 里看“当前活动连接 / 日志”，访问本页时应出现对应目标域名。
  2. 检查 v2rayN 的“服务器 / 节点”列表和当前选中项；页面检测到的 IP 只代表最终出口。
  3. 如果要定位具体组和节点，需要把节点的出口 IP 与检测结果匹配，或开启本机 API 后接入查询。

推荐验证顺序：先切换 v2rayN 节点 → 重新检测 → 对比 ChatGPT、Gemini、YouTube 的出口 IP 和可用性。

说明：超时、CDN、IPv4/IPv6 和代理模式都会影响结果；本页不上传 v2rayN 配置。
